# MidnightWorks Test Task — Auto Service Management 3D Idle Tycoon

Проект выполнен в рамкаx тестового задания на вакансию **Unity Game Developer** компании **MidnightWorks**.

## 📌 Версия Unity & Требования
- **Unity Version:** 6000.3.17f1
- **Render Pipeline:** Built-in / URP (совместимый 3D рендер)
- **Библиотеки:** 0 внешних сторонних библиотек (без DOTween, Zenject, UniTask, LeanTween — строго нативные средства Unity).
- **Платформа:** PC Standalone / Unity Editor.

---

## 🚀 Быстрый запуск и проверка (Гайд для проверяющего)

Для удобной и мгновенной проверки всей функциональности без необходимости тратить время на долгий геймплей добавлена **Дебаг-панель (F1)**:

1. Откройте сцену: `Assets/_Project/Scenes/Gameplay.unity`.
2. Нажмите кнопку **Play** в Unity Editor.
3. Нажмите клавишу **[F1]** на клавиатуре или кнопку **[F1]** в правом верхнем углу экрана.
4. В дебаг-панели доступны функции:
   - **`+ $1,000`** / **`+ $10,000`** — мгновенное добавление игровой валюты.
   - **`+ 1 Уровень (Level Up)`** — мгновенный подъем уровня (открывает новые зоны и сервисы).
   - **`Телепорт: Локация 1`** / **`Телепорт: Локация 2`** — мгновенный переход игрока на соответствующую локацию.
   - **`Сброс прогресса`** — сброс сохранения до начального состояния.

## 🏗 Архитектура Проекта

Проект спроектирован по принципам **Clean Architecture** и паттерну **MVP (Model-View-Presenter)** с четким разделением по Assembly Definitions (`.asmdef`):

- `AutoService.Domain` — базовые сущности и модели данных (PlayerBalance, ServiceLevel, StaffModel, Vehicle, etc.).
- `AutoService.Services` — бизнес-логика (EconomyService, ProgressionService, StaffService, AudioService, UpgradeService).
- `AutoService.Infrastructure` — сохранение прогресса (`PlayerPrefs`), загрузка конфигов (`ScriptableObjects`), управление настройками.
- `AutoService.Presentation` — представление (Presenters, Views, HUD, World-space UI, Popups).
- `AutoService.Bootstrap` — точка входа (`GameplayEntryPoint`), сборка зависимостей и инициализация всех систем.
- `AutoService.Bootstrap.Editor` — утилиты автоматизации сцены и конфигов.

## 🎮 Реализованный функционал (100% ТЗ)

### Локация 1:
- Игрок под управлением NavMesh / CharacterController (джойстик / WASD / клики).
- Въезд авто через шлагбаум, автоматический поиск свободного поста обслуживания.
- Обслуживание машин, заработок денег, начисление XP игроку.
- Зона пополнения расходников (Warehouse) с визуалками коробок и колес.
- Наем и авто-байт работников (работник самостоятельно берет заказ и обслуживает авто).
- Прокачка постов (Level / Speed / Revenue).

### Локация 2:
- Разблокировка по достижении 2-го уровня игрока с выплывающим приветственным окном (`Location2WelcomePopup`).
- Усовершенствованные модели складов и декор (автомобильная парковка, высотки, барьеры).
- Автоматическая логика работы персонала и навигации NavMesh.

### UI & UX:
- **HUD верхней панели:** Баланс $, индикатор уровня и прогресс-бар XP.
- **Всплывающие окна:** `LevelUpPopup` при повышении уровня, `Location2WelcomePopup` при открытии 2-й локации.
- **Панель настроек:** Регуляторы громкости (Master, SFX, Music) с сохранением в `PlayerPrefs`.
- **Звуки (SFX):** Нативный `AudioService` (клики кнопок, выдача денег, завершение сервиса, повышение уровня).
