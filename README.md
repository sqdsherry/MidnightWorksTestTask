# Auto Service Management — 3D Idle Tycoon

Тестовое задание на позицию Unity Game Developer для компании **MidnightWorks**.

## Стек и ограничения
- **Версия движка:** Unity `6000.3.17f1` (URP).
- **Библиотеки:** 0 сторонних ассетов (без Zenject, DOTween, UniTask и т.д. — только нативные средства Unity).
- **Платформа:** PC Standalone / Editor.

---

## Быстрая проверка (Дебаг-панель F1)

Чтобы не тратить время на гринд и проверить весь функционал за пару минут:

1. Откройте сцену `Assets/_Project/Scenes/Gameplay.unity` и нажмите **Play**.
2. Нажмите **`F1`** на клавиатуре (или кнопку `[F1]` в правом верхнем углу).
3. В панели доступны быстрые действия:
   - `+ $1,000` / `+ $10,000` — выдача денег.
   - `+ 1 Level` — повышение уровня (триггерит окно нового уровня и открывает Локацию 2).
   - `Телепорт: Локация 1 / Локация 2` — перемещение персонажа между зонами.
   - `Сброс прогресса` — очистка сохранения в `PlayerPrefs`.

## Архитектура

Проект реализован по правилам **Clean Architecture** и паттерну **MVP (Model-View-Presenter)** с разделением сборок по Assembly Definitions (`.asmdef`):

- **`AutoService.Domain`** — чистые C# модели, события и бизнес-сущности без зависимости от UnityEngine.
- **`AutoService.Services`** — сервисы экономики, прогрессии, работы складов, трафика и персонала.
- **`AutoService.Infrastructure`** — нативное сохранение (`PlayerPrefs`), загрузка конфигов (`ScriptableObject`), аудио-сервис.
- **`AutoService.Presentation`** — визуальные компоненты, презентеры, HUD, world-space UI и всплывающие окна.
- **`AutoService.Bootstrap`** — точка входа (`GameplayEntryPoint`) и простой собственный Service Locator для инициализации.
- **`AutoService.Bootstrap.Editor`** — утилиты авто-настройки сцены и компонентов.

## Игровые системы

### Локация 1
- **Персонаж:** Управление через WASD / клики мыши / джойстик.
- **Трафик и посты:** Машины заезжают через шлагбаум, выбирают свободный пост (мойка, масло, шиномонтаж) и обслуживаются.
- **Склад:** Механика пополнения расходников (игрок приносит коробки/шины к постам).
- **Персонал:** Наём работников, которые автоматически берут заказы и выполняют работу.

### Локация 2
- **Разблокировка:** Открывается при достижении 2-го уровня с показом приветственного окна (`Location2WelcomePopup`).
- **Новые сервисы:** Покраска, новые шинные посты и тюнинг-бокс.
- **Окружение:** Декоративные здания, расширенная парковка и обновлённые модели складов.

### UI & Звук
- **HUD:** Баланс $, уровень и прогресс-бар XP.
- **Окна:** `LevelUpPopup` при повышении уровня, `Location2WelcomePopup` при переходе на 2-ю локацию.
- **Настройки:** Слайдеры громкости (Music / SFX) с сохранением в `PlayerPrefs`.
- **Аудио:** Нативный `AudioService` (клики кнопок UI, получение денег, завершение ремонта).
