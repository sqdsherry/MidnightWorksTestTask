# Auto Service Tycoon — 3D Idle Tycoon

Тестовое задание Unity Developer: idle-тайкун про автосервис. Машины заезжают на парковку и мойку, игрок сам
работает на постах, строит новые боксы и парковочные места, нанимает персонал, носит расходники со склада и
открывает вторую локацию — тюнинг-центр.

- **Unity:** `6000.3.17f1`, URP, PC (landscape). UI — на английском.
- **Сторонние библиотеки:** нет. Только пакеты `com.unity.*` (Input System, AI Navigation, TextMesh Pro, URP).
  Ни Zenject, ни DOTween, ни UniTask — DI, твины и пулы написаны вручную.

## Запуск

1. Откройте проект в Unity `6000.3.17f1` (первый импорт занимает несколько минут).
2. Нажмите **Play** в любой сцене — Editor-утилита всегда стартует со сцены `Boot`
   (как в билде): `Boot` → экран загрузки → `MainMenu` → **New Game** / **Continue** → `Gameplay`.

Сцены в билде: `Boot`, `MainMenu`, `Gameplay` (`Assets/_Project/Scenes`).

## Управление

| Действие | Ввод |
|---|---|
| Идти / работать на посту / взаимодействовать | **ЛКМ** по полу или по объекту |
| Двигать камеру | **WASD** / стрелки / курсор у края экрана |
| Зум | колесо мыши |
| Вернуть камеру к персонажу | **Space** |
| Пауза / закрыть окно | **Esc** |
| Debug-панель | **F1** или кнопка в углу HUD |

Строительство, найм и улучшения — «подойди и постой»: персонаж встаёт на полупрозрачный участок или синюю
площадку, заполняется кольцо, и открывается панель покупки.

## Гайд для проверяющего

**Обычная сессия (≈5–10 минут до второй локации):**
1. **New Game.** Старт — $100, открыты парковка, мойка и два въездных шлагбаума.
2. Кликните по шлагбауму или посту: персонаж встаёт на его рабочую точку и принимает машины.
   Пока игрок или работник стоит на точке, идёт приём и обслуживание; ушёл — работа на паузе.
3. Каждая услуга тратит расходник поста. Когда он кончается, возьмите ящик на складе (клик) и отнесите к посту.
4. За услуги начисляются деньги и XP. Уровни: 2 — 15 XP, 3 — 35, 4 — 70, 5 — 110, дальше +50 за уровень.
   В окне нового уровня перечислено, что он открывает (список собирается из конфига построек).
5. На заработанное стройте: Wash Bay 2 и Parking Spot 3 (ур. 2), Oil Change 1 и Parking Spot 4 (ур. 3),
   Oil Change 2 (ур. 4). На синей площадке поста — найм работника и улучшения, у склада — кладовщик (ур. 3).
6. **Уровень 2 и $250** — участок переезда «Travel to Location 2». Встаньте на построенный пад —
   персонаж переедет в тюнинг-центр (при первом визите появится приветственное окно).
   Там строятся Tires (ур. 2), Tuning (ур. 3) и Paint (ур. 4); машины после тюнинга и покраски меняют вид.
7. Прогресс сохраняется автоматически (каждые 30 с, после важных действий, при паузе и выходе).
   **Continue** в меню продолжает игру.

**Быстрая проверка за минуту — F1:**
- `+ $1,000` / `+ $10,000` — деньги;
- `+1 Level` — уровень (откроется окно уровня);
- `Teleport: Location 1 / 2` — перенести персонажа между локациями;
- `Reset Progress` — удалить сохранение и перезапустить сцену (настройки игрока не трогаются).

## Системы (по пунктам ТЗ)

| Требование | Реализация |
|---|---|
| Ядро игры | `GameLoop` (единственный геймплейный `Update`, фазы тика), посты обслуживания (`ServicePointService`), трафик машин по графу дорог с очередями и шлагбаумами (`LocationTraffic`, `CarAgents`) |
| Строительство и расширение | Участки построек на конфигах (`BuildService`, `BuildPlotView`): боксы, парковочные места, переезд на вторую локацию |
| AI | Машины едут по графу дорог; работники постов и кладовщики ходят по NavMesh (`StaffService`, `StaffAgents`); кладовщик сам носит ящики туда, где расходника меньше всего |
| Ресурсы / баланс | Кошелёк (`WalletService`), цены по формуле из конфига, расходники постов (`SupplyService`) |
| Сохранения | JSON-файл в `Application.persistentDataPath` с атомарной записью (`FileSaveStorage`, `SaveCoordinator`): деньги, XP/уровень, постройки, апгрейды, персонал, запасы |
| Прогрессия | Таблица уровней (`LevelTable`), XP за услуги, постройки открываются уровнем (`LevelUnlockGate`), вторая локация |
| Главное меню | Continue / New Game (с подтверждением) / Settings / Quit |
| Настройки | Громкость SFX и музыки, качество, полноэкранный режим, разрешение; хранятся в `PlayerPrefs` |
| Экран загрузки | Асинхронная загрузка сцен с прогресс-баром и подсказками (`UnitySceneLoader`, `LoadingScreenView`) |
| Внутриигровой UI | Баланс, уровень и XP-бар, пауза, панели постройки / найма / улучшений, HUD постов, всплывающие «+$», окна уровня и второй локации |
| Звук | `IAudioService`: клик на всех кнопках (меню и игра), деньги, завершение услуги, новый уровень; громкость SFX по умолчанию 10 % |

## Архитектура

Код — `Assets/_Project/Scripts`, по сборке (`.asmdef`) на слой:

```
Presentation ──► Services ──► Domain
Infrastructure ──► Services, Domain   (реализует интерфейсы Services)
Bootstrap ──► все (Composition Root)
```

- **Domain** — чистые модели и правила (деньги, посты, очереди, уровни). Без `UnityEngine` (`noEngineReferences`).
- **Services** — игровая логика и контракты (`IWalletService`, `ISaveService`, `IAudioService`…). Тоже без `UnityEngine`.
- **Infrastructure** — реализации на Unity: ScriptableObject-конфиги, сохранение в файл, `PlayerPrefs`, звук, загрузка сцен.
- **Presentation** — MonoBehaviour-вью и презентеры (MVP): HUD, панели, персонаж, машины, камера.
- **Bootstrap** — точки входа сцен и инсталлеры.

Принципы:
- **DI без контейнеров-фреймворков.** `ProjectEntryPoint` (сцена `Boot`, живёт всю сессию) создаёт проектные
  сервисы; каждая сцена получает их в `ISceneEntryPoint.Enter`, а `GameplayEntryPoint` собирает сцену набором
  инсталлеров. Зависимости передаются через конструктор или `Construct(...)`; синглтонов и статического состояния нет.
- **Один геймплейный `Update`.** Всё тикает через `GameLoop` по фазам
  (`Input → Simulation → Traffic → Staff → Agents → Trackers → Presentation`); в тике нет аллокаций.
  Исключение — `LateUpdate` камеры: она следует за персонажем уже после шага NavMesh.
- **События.** Сквозные — через `IEventBus` (`readonly struct`, без аллокаций), локальные — C#-события сервиса;
  у каждой подписки есть отписка.
- **Данные — в конфигах.** Цены, уровни, постройки, типы машин и услуг — ScriptableObject в `Assets/_Project/Configs`.
- **Пауза** — счётчик в `IPauseService` (`timeScale`); UI-анимации идут на unscaled time.

Подробности: [`Docs/TDD.md`](Docs/TDD.md) (архитектура и контракты модулей), [`Docs/GDD.md`](Docs/GDD.md) (геймдизайн).
