# Task: 13b - In-World & Context Popups Visual Polish (Reskin & Kenney UI)

**Branch:** `feature/13b-context-popups-reskin`
**Base:** `main`

## Контекст и цели
В проекте реализованы базовые окна и всплывающие мини-панели (контекстные окна точек, покупка/апгрейд `OfferPanelView`, мини-окошки работников/склада, карточки взаимодействия в мире). Сейчас они выглядят просто/дефолтно. Нужно сделать их аккуратными, сочными и выдержанными в общем стиле Kenney UI, как главное меню и экран настроек.

## Задачи для Кодера

### 1. Рескин мини-окошек и панелей (World & Screen Context UI)
- Проинспектировать все контекстные панели:
  - `OfferPanelView` (окно покупки/постройки/апгрейда).
  - Панели найма персонала / управления боксом.
  - HUD над сервисными точками (`ServicePointHud`, индикаторы расходников и прогресса).
- **Стилизация под Kenney UI:**
  - Заменить стандартные белые/серые плашки на 9-slice спрайты из папки ассетов UI (скругленные подложки, рамки).
  - Настроить контрастную цветовую палитру: приятный фон (тёмно-синий/графитовый или стилизованный бежевый), акцентные кнопки (зелёные для покупки/Buy, синие/оранжевые для улучшений).
  - Убедиться, что текст использует `TextMeshPro` с четкими отступами, читаемым размером и жирными заголовками.

### 2. Подключение анимаций появления и нажатий
- На все мини-окошки повесить компонент `UiWindowAnimator` (нативный скейл + фейд из модуля 12b), чтобы окна открывались плавно с микро-отскоком, а не выскакивали резко.
- На все кнопки внутри этих мини-окон повесить `ButtonAnimator` для тактильного отклика при клике.

### 3. Ограничения (Строго по ТЗ)
- **Никаких сторонних библиотек:** строго нативный uGUI, CanvasGroup, корутины, без DOTween и UniTask.
- Код только в слое Presentation (`Assets/_Project/Scripts/Presentation/`).
