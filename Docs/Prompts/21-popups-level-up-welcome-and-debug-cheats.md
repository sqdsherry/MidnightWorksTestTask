## 1. Попап повышения уровня (`LevelUpPopupView` + `LevelUpPresenter`)

### 1.1. Описание
При повышении уровня игрока (`IProgressionService.LevelChanged`) открывается красивое модальное окно с затемнением фона, поздравляющее игрока и рассказывающее, какие новые услуги и возможности стали доступны.

### 1.2. Данные по уровням (Что разблокировано)
- **Уровень 2:** "Разблокирована Автомойка 2 и Замена масла!" (Новые боксы на Локации 1).
- **Уровень 3:** "Разблокирован второй бокс замены масла!" (Увеличение потока клиентов).
- **Уровень 4:** "Разблокирован переезд на Локацию 2 — Тюнинг-Центр!" (Доступен шлагбаум переезда).
- **Уровень 5:** "Максимальный уровень мастерской! Все сервисы разблокированы!"

### 1.3. Визуальная структура попапа
Создать префаб или объект в Canvas `Gameplay.unity` (`LevelUpPopup`):
- **Overlay (Затемнение):** Растянутый Image с цветом `RGBA(0, 0, 0, 0.6)`. Блокирует клики сквозь окно.
- **Card (Карточка):** Центрированная панель размером `450 x 320`.
  - Background Image: спрайт `button_rectangle_depth_flat.png` (цвет светлый бежевый/серый `#F5F6FA`).
  - **Star Icon:** Иконка звездочки (`star.png` из Kenney UI) сверху по центру.
  - **Title:** TMP текст `НОВЫЙ УРОВЕНЬ!` / `LEVEL UP!` (шрифт LiberationSans SDF, размер 32, жирный, темно-синий `#1E2430`).
  - **Level Badge:** TMP текст `УРОВЕНЬ {0}` (размер 24, зеленый `#2ECC71` или синий `#3498DB`).
  - **Unlocked Description:** TMP текст с описанием открытых сервисов (размер 18, серый `#4A5568`, выравнивание по центру, перенос строк).
  - **Continue Button:** Кнопка «ПРОДОЛЖИТЬ» снизу (`button_rectangle_depth_flat.png`, зеленая, текст белый 20pt).

### 1.4. Логика View (`LevelUpPopupView.cs`)
- Методы:
  - `Show(int newLevel, string unlockedDescription, Action onClose)`
  - `Hide()`
- Анимация появления: короткая корутина плавного зума карточки от `Vector3.one * 0.7f` до `Vector3.one` за 0.25 сек.
- При клике на кнопку «ПРОДОЛЖИТЬ» — вызов `Hide()` и коллбэка `onClose`.

## 3. Дебаг-панель для проверяющего по клавише F1 (`DebugCheatView`)

### 3.1. Требование ТЗ (п. 85)
> «README: гайд по геймплею для проверяющего — что делать по шагам, сколько длится сессия до 2-й локации (~10 мин), горячие клавиши debug-панели (F1) для ускорения»

Проверяющий должен иметь возможность протестировать открытие всех уровней, наем рабочих и кастомизацию машин за 1 минуту без гринда.

### 3.2. Визуальная структура и функционал
Панель `DebugCheatPanel`:
- Скрыта по умолчанию.
- Открывается/закрывается по нажатию клавиши **`F1`** (а также через маленькую иконку гаечного ключа ⚙️ в углу экрана для тестирования на мобилках/мышью).
- Содержит кнопки быстрого тестирования:
  1. **`+ $1,000`** — добавляет $1,000 на счет игрока (`IPlayerWallet.AddMoney(1000)`).
  2. **`+ $10,000`** — добавляет $10,000 на счет игрока (`IPlayerWallet.AddMoney(10000)`).
  3. **`+ 1 Уровень (Level Up)`** — добавляет достаточно XP для перехода на следующий уровень (`IProgressionService.AddExperience(...)`), что автоматически триггерит попап Level Up!
  4. **`Телепорт: Локация 1`** — мгновенно переносит игрока на координаты Локации 1.
  5. **`Телепорт: Локация 2`** — мгновенно переносит игрока на координаты Локации 2.
  6. **`Сброс прогресса`** — стирает сохранения `PlayerPrefs` и перезагружает сцену.

### 3.3. Реализация скриптов
1. `Assets/_Project/Scripts/Presentation/UI/DebugCheatView.cs`:
   - Наследует `MonoBehaviour`.
   - Слушает нажатие `Keyboard.current.f1Key.wasPressedThisFrame` (Input System) или `Input.GetKeyDown(KeyCode.F1)`.
   - Имеет `[SerializeField]` ссылки на кнопки и корень панели `_panelRoot`.
2. Подключение в `GameplayEntryPoint.cs` / `HudInstaller.cs`:
   - Инициализируется с сервисами `IPlayerWallet`, `IProgressionService`, `PlayerView`.

## 5. Критерии приемки
1. При получении опыта и достижении 2, 3, 4 уровня на экране плавно появляется аккуратный попап Level Up с описанием открытого контента. Кнопка «Продолжить» закрывает окно.

4. Все окна используют стилистику и ассеты Kenney UI.
