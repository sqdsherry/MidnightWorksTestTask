# Task: 12b UI & Audio (Juice)

**Branch:** `feature/12b-ui-audio`
**Base:** `main`

## ЗАПРЕТ НА СТОРОННИЕ БИБЛИОТЕКИ
Внимание! В проекте строжайше **ЗАПРЕЩЕНО** использовать любые сторонние библиотеки (никакого DOTween, Zenject, UniTask и т.д.). Все анимации и системы должны быть написаны исключительно на нативных инструментах Unity (Coroutines, AnimationCurve, Animator).

## Задачи для Кодера
В этом модуле мы должны оживить игру (juice) и привести UI в опрятный вид, используя только базовый функционал Unity.

### 1. Всплывающий текст доходов (Floating Text / Juice)
* Реализовать систему всплывающего текста, когда игрок (или касса) получает деньги.
* **Где:** В момент завершения обслуживания машины на точке (или на кассе).
* **Визуал:** Текст вида `+$100` появляется над точкой, отлетает немного вверх, плавно исчезает (Fade) и уничтожается.
* **Технически:** Напиши простую корутину с использованием `AnimationCurve` для движения по Y и изменения альфа-канала у `TextMeshProUGUI` или `TextMeshPro`. Сделай спаунер/пул для этих текстов.

### 2. Анимации попапов (UI Popups)
* Окна найма, улучшения, меню настроек и другие экраны не должны появляться мгновенно.
* Напиши переиспользуемый компонент (например, `UiWindowAnimator`), который при открытии (через корутину) делает скейл от `0.8` до `1.0` (используй `AnimationCurve` для эффекта Overshoot/OutBack) и Fade от 0 до 1 через `CanvasGroup`. При закрытии — обратная анимация.

### 3. Базовый рескин UI
* Замени дефолтные белые Unity-спрайты в окнах и кнопках на более аккуратные (настрой цвета, скругления, шрифты).
* Назначь везде единый шрифт `TextMeshPro`.
* Кнопкам (Button) добавь микро-анимацию при нажатии (например, изменение `transform.localScale` на 0.95 при PointerDown и обратно при PointerUp/Click) с помощью интерфейсов `IPointerDownHandler`/`IPointerUpHandler`.

### 4. Звуки (Опционально / Заглушки)
* Подготовь `IAudioService` (в `Domain/Services` или `Infrastructure/Services`), который умеет играть `PlaySfx(AudioClip)` и `PlayMusic(AudioClip)`.
* Добавь вызовы звуков (через `Debug.Log` внутри сервиса, если самих клипов пока нет) на:
  * Клик по кнопкам UI.
  * Получение денег (Cash).
  * Выполнение работы на точке.

## Требования к архитектуре
* Не забывай про `noEngineReferences` в Domain/Services. Сервис звуков должен иметь интерфейс в Domain, а реализацию (`AudioService`) в Infrastructure.
* Анимации UI должны лежать строго в слое Presentation.
* Использовать Корутины, `System.Action` коллбеки или стандартный `async/await` (Task) для ожидания окончания анимации закрытия окна перед его скрытием. Никакого UniTask.
