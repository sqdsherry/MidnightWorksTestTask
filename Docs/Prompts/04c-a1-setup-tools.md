# Промпт 04c (фикс A1) — два бага после Editor-проверки

**Ветка:** та же `feature/04-build`. Маленький фикс, один коммит.

## 1. Панель стройки не показывается, если `BuildPanel` выключен в сцене
`BuildPanelView.Show()` включает только `_root` (дочерний `Panel`). Если сам объект с `BuildPanelView` неактивен, панель остаётся невидимой.

Исправить:
- `BuildPanelView.Show()`: если `!gameObject.activeSelf` → `gameObject.SetActive(true)`, затем включить `_root`, как сейчас.
- `Hide()` по-прежнему прячет только `_root`. `// Why:` контейнер должен оставаться активным, иначе `Awake` / слушатели кнопок и `GetComponentInParent<Canvas>` не отработают.
- В `Awake` уже есть замечание про неактивный объект. Убедиться, что двойной `Awake` невозможен и `AddListener` не дублируется: `Awake` вызывается один раз за жизнь объекта, но проверь.
- **Правило на будущее для всех view-панелей:** `Show` сам гарантирует `SetActive(true)` всей цепочки до своего корня. Состояние объекта в сцене не должно влиять на работу.

## 2. Призраки мест парковки не кликаются
В `WhiteboxLocationBuilder.PlaceParkingGhosts` площадка призрака 0.05 высотой стоит на y = 0, её верх (0.05) совпадает с верхом `Surface_Parking` (толщина 0.1, центр y = 0). Луч из `PointerRaycaster` первым попадает в коллайдер дороги (Ground), клик уходит в землю.

Исправить в builder:
- Площадку (`Visual/pad`) поднять так, чтобы её низ был над дорогой: `localPosition.y = 0.06`, толщина 0.05.
- Кликабельный `BoxCollider` на корне призрака (слой Interactable): центр (0, 0.25, 0), размер (2.2, 0.5, 4.4), то есть объём над дорогой. `// Why:` плоские призраки на асфальте иначе уступают лучу коллайдер дороги.
- Тот же принцип проверь у призраков боксов: их коллайдер не должен совпадать по высоте с `Surface_ServiceArea`.
