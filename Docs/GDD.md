## 0. TL;DR

3D idle-tycoon про автосервис. Игрок — механик-владелец, бегает по кликам между точками (шлагбаум парковки, мойка, склад...), сам принимает машины и обслуживает их, а потом нанимает NPC, которые делают это за него. Растёт от «бегаю как белка между двумя точками» до «управляю двумя локациями, веду переговоры с VIP».

**Платформа:** PC (landscape, мышь + клавиатура). **Язык UI:** английский. **Сессия проверяющего:** ~15 минут должны показать все системы.

## 0.1 Скоуп — дедлайн 3–4 дня ✅

| Приоритет | Что входит |
|---|---|
| **[M] Must** | Персонаж click-to-move, шлагбаум + парковка, машины (3 типа), точки услуг, склад + расходники + кладовщик, работники точек, строительство (фикс. участки), прогрессия + разблокировки, 2-я локация (минимум: шлагбаум + 2 точки), сейв, все 4 UI-экрана + HUD + панели, онбординг, единый визуал |
| **[S] Should** (день 4) | VIP + переговоры, поломки + ремонт, терпение с уходом злых клиентов |
| **[C] Could** | Облачка-реплики, зал ожидания, апгрейд грузоподъёмности, debug-панель |
| **Бэклог** | Чаевые + рейтинг, всё из 💡 |

Типы точек урезаны: **Лок. 1** — мойка, масло, шиномонтаж; **Лок. 2** — тюнинг, покраска.

## 2. Столпы (pillars)

1. **«Не могу быть везде»** — напряжение от того, что игрок один, а точек несколько.
2. **Видимая автоматизация** — каждая нанятая единица снимает конкретную боль, и это видно глазами (NPC пришёл и встал на место).
3. **Честная обратная связь** — каждое действие отвечает: «+$», звук, прогресс-бар, облачко.

## 3. Core loop ✅

Схема локации (вид сверху, **одностороннее движение**, v2 — модуль 03b):
```
 север
   ┌───────────── выездная полоса ──────────────────────────────►┐
   │         ↑ выезд из бокса                                     │
   │      [Мойка]  [Масло]  [Шины]     ← проездные боксы          │
   │         ↑ въезд в бокс                                       │
   ├───── полоса к боксам ◄────────(S)◄──────┐                    │
   ↑                                         │                    │
   │                [P0][P1][P2][P3] ──► [Шлагбаум выезда] ─┬─────┘ (на бокс)
   │(F)               ↑ парковка                            └──► (M) (на выезд)
 ══╪═ очередь Q3..Q0 ══► [Ворота въезда, авто]                    │
 ══════════════════ сквозная полоса ═══════════════════════════(M)═══► Выезд
 юг
```
- **Ворота въезда на парковку — автоматические** (без исполнителя, бесплатно): просто открываются перед машиной.
- **Шлагбаум выезда с парковки — точка с исполнителем.** Через него проходят **все** машины, покидающие парковку (и «только парковка», и «потом на мойку»). Оплата **за время стоянки**: `(база + ставка × секунды на парковке) × множитель машины`.
- **(S), (M) — зоны слияния**: в зоне одновременно одна машина, остальные ждут перед ней.
- Машины едут по **маршрутам** (цепочки точек на сцене), а не по кратчайшему пути: не проезжают сквозь шлагбаум, очередь и встречных.

```
Машина встаёт в очередь-полосу на дороге (полна → не появляется; позже — проезжает мимо)
  → план при спавне: «только парковка» (шанс) или «услуга» (случайная из боксов локации)
  → голова очереди у развилки (F):
      ├─ услуга + бокс свободен + никто с парковки его не ждёт → полоса к боксам → бокс
      └─ иначе есть место на парковке → ворота (авто) → место P (стоянка 6–15 с, терпение не тратится)
             → таймер вышел:
                 «только парковка» → [Шлагбаум выезда] (исполнитель) → +$ за время → (M) → выезд
                 «услуга» → ждёт свободный бокс (терпение тикает) → [Шлагбаум выезда] → +$ → (S) → бокс
  → [Бокс] исполнитель + расходник + не сломан → принять → +$ за услугу, −1 расходник
  → обслуживание N сек (только пока на WorkSpot кто-то стоит)
  → выезд из бокса → выездная полоса → (M) → выезд → +XP, шанс поломки
```

Мета-петля: деньги → строю/улучшаю/нанимаю → больше потока и автоматизации → больше денег → новый уровень → новые точки / 2-я локация.

## 4. Игрок ✅

### 4.1 Управление
- **ЛКМ по точке** → персонаж идёт на её `WorkSpot` и начинает работать.
- **ЛКМ по полу** → просто идёт туда (для отзывчивости).
- Новый клик прерывает текущее действие. Очереди команд нет.
- **Камера** следует за персонажем; **WASD / край экрана** — сдвиг; **колесо** — зум; **Space** — вернуть к персонажу; **Esc** — пауза / закрыть панель.

### 4.2 Правила мира
1. У каждой точки ровно **один WorkSpot**. На нём стоит либо игрок, либо работник — не оба.
2. Приём **и** обслуживание идут только пока WorkSpot занят. Ушёл — прогресс на паузе (не сбрасывается).
3. Оплата списывается **в момент приёма**.
4. Каждая услуга тратит **1 расходник** точки. Шлагбаум расходник не тратит → у игрока всегда есть доход → нет софтлока.

### 4.3 Действия

| Действие | Как | Условие | Результат | Автоматизация |
|---|---|---|---|---|
| Идти | клик по полу | — | идёт | — |
| Работать | клик по точке | WorkSpot свободен | принимает/обслуживает | Работник точки |
| Взять ящик | клик по складу | руки пусты | ящик в руках, −$ | Кладовщик |
| Пополнить | клик по точке с ящиком | тип совпадает | +N расходника | Кладовщик |
| Ремонт | клик по сломанной точке, **удержание ЛКМ 2 с** | точка сломана | точка работает | Работник чинит сам, медленно (~10 с) |
| VIP-переговоры | попап | VIP приехал | §5.3 | NPC может, но без премии |
| Строить / улучшать / нанимать | клик по «призраку» / точке → панель | $ + уровень | постройка/апгрейд | — |

### 4.4 Состояния персонажа
`Idle → Moving → Working(point) | Repairing(point)` + флаг `Carrying(boxType)`.
Прервал ремонт — прогресс ремонта теряется. Ящик остаётся в руках, пока не доставлен.

## 5. Клиенты (машины)

### 5.1 Поток ✅ / цифры 🟡
- Машины спавнятся за краем карты с интервалом `spawnInterval` (зависит от уровня / числа мест).
- Каждая машина запрашивает **одну услугу** из уже построенных в локации.
- Машины встают в **очередь-полосу** перед развилкой (N мест 🟡, ~4). Если полоса полная — машина пока просто не появляется (💡 проезд мимо по сквозной полосе с облачком «Нет мест!» — бэклог).
- **План визита** при спавне: «только парковка» (`ParkOnlyChance`, 0.4 🟡) или «услуга». Стоянка на парковке — случайно 6–15 с 🟡.
- Голова очереди ждёт у развилки. Если парковка полная и точка занята — очередь стоит (терпение тикает у всех).

### 5.2 Типы машин 🟡
| Тип | Множитель оплаты | Шанс | Терпение |
|---|---|---|---|
| Седан | ×1 | 60% | базовое |
| Внедорожник | ×1.5 | 30% | базовое |
| Спорткар | ×2.5 | 10% | −30% |

### 5.3 VIP ✅
- Редко (~раз в 2–3 мин 🟡), сопровождается уведомлением.
- **Попап (игра на паузе):** «VIP-клиент на {точка}» →
  - **«Обслужу сам»** → персонаж идёт на точку → переговоры:
    - *Стандарт* — ×2 гарантированно;
    - *Торг* — ×3.5 с шансом 60% 🟡, иначе клиент уезжает.
  - **«Пусть персонал»** → базовая цена, **лояльность VIP падает** → VIP реже.
- **Лояльность VIP** — число 0..1, влияет на частоту VIP. Сохраняется.

### 5.4 Облачка-реплики 🟡 (опциональный пункт ТЗ)
Короткие реплики над машинами/NPC по событиям: «Нет мест!», «Долго ещё?» (терпение < 30%), «Отлично!» (обслужили быстро), «Сломалось!» и т.п. Пул облачков, без аллокаций.

### 5.5 Терпение ✅
Тикает, пока машина ждёт (на парковке и в ожидании приёма у точки). Зал ожидания замедляет убывание.

## 6. Строительство ✅ / цены 🟡

**Только фиксированные участки**, заранее размеченные на сцене (свободной расстановки нет). Один тип точки может стоять на нескольких участках (например, 2 мойки), если так размечено — диспетчер работает с N точками одного типа.

На карте — полупрозрачные «призраки» будущих построек с ценником (или замком + «Ур. N»). Клик → панель «Построить за $X» → анимация стройки (масштаб + частицы).

### Локация 1 — «Гараж»
| Постройка | Тип | Что даёт | Расходник |
|---|---|---|---|
| Шлагбаум парковки | точка (старт) | приём на парковку, +$ | — |
| Мойка | точка (старт) | услуга «Мойка» | шампунь |
| Места парковки | расширение | +2 места за покупку | — |
| Склад | здание (старт? ❓) | источник ящиков | — |
| Замена масла | точка | услуга | масло |
| Шиномонтаж | точка | услуга | шины |
| Покраска | точка | услуга | краска |
| Зал ожидания | здание | терпение клиентов ↑ | — |

### Локация 2 — «Тюнинг-ателье»
Отдельная огороженная зона на той же сцене (через дорогу). Открывается по уровню + покупке. Свой шлагбаум, свой склад, дорогие точки (тюнинг, винил 🟡). Переключение камеры кнопками в HUD. Арка «всё руками → найм» повторяется, но с большими деньгами.

## 7. Персонал ✅

| NPC | Где | Нанимается | Что делает |
|---|---|---|---|
| Работник точки (парковщик, мойщик…) | свой WorkSpot | на конкретную точку | принимает и обслуживает; чинит медленно |
| Кладовщик | склад ↔ точки | на локацию | носит ящики туда, где расходника меньше всего |

NPC приходят из «комнаты персонала» по NavMesh — найм виден глазами.

## 8. Экономика 🟡

- **Одна валюта: $**.
- **Доход:** плата за парковку + плата за услугу × тип машины × апгрейд цены (× VIP).
- **Расходы:** ящики расходников, постройки, апгрейды, найм.
- **Апгрейды точки** (~10 уровней): *Скорость*, *Цена*, *Надёжность* (шанс поломки ↓). Стоимость: `base × growth^level`.
- **Апгрейд персонажа:** грузоподъёмность +1 ящик ❓.

> Баланс — следующий этап. Цель: первые 3–4 мин беготня, первый найм (парковщик) ~на 2-й минуте, 2-я локация ~на 10–12 минуте.

## 9. Прогрессия 🟡

- **XP** за каждую обслуженную машину (зависит от услуги и типа).
- **Уровень** → разблокировки. Попап «Новый уровень!» со списком открытого.

### Онбординг ✅
1. «Кликни по шлагбауму — прими машину»
2. «Беги на мойку — помой машину»

## 11. Визуальный стиль 🟡

Low-poly toon. Кандидаты (CC0): **Kenney Car Kit**, **Kenney City Kit (Commercial / Roads)**, персонажи **Kenney Mini Characters** или **Quaternius**. Одна палитра, один шрифт, один UI-скин.

**Ориентир — пример из ТЗ** (см. [TZ.md](TZ.md)): изометрия сверху ~45°, чиби-персонажи, яркие чистые цвета, мягкий свет, минималистичный HUD (деньги справа сверху, пауза слева сверху). Наша камера — такой же угол, но с follow за персонажем и зумом, т.к. локаций две.

## 12. Звук 🟡
Фон — лёгкий lo-fi луп. SFX: монеты, клик, стройка, мойка, поломка, гудок машины. (CC0 — Kenney Audio.)

## 💡 Идеи — если успеем

- **Проезд мимо при полной очереди** — машина едет по сквозной полосе с облачком «Нет мест!» (живость + сигнал «расширяй парковку»).
- **Визуал дорог** (этап ассетов): нормальные повороты, точки маршрутов по разметке, полосы — переставить точки, код не трогать.
- **Чаевые + рейтинг сервиса** (звёзды) — быстрый сервис → чаевые-монетка (клик, 3 с), рейтинг влияет на поток клиентов. Лояльность VIP — уже задел под это.
- Апгрейд скорости ходьбы персонажа.
- «Час пик» — событие ×2 поток на 60 с.
- Декор (клумбы, флаги) за $ — +к терпению.
- Смена дня/ночи (визуал).
- Статистика за сессию (обслужено, упущено, заработано).
